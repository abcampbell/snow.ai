THE CONDITIONAL MACHINE

regime-conditional beta engine — Castra Capital Research · 2026-07-03
I · THE TIME MACHINE
Set any date in history (2010–2026). The machine sees only what was knowable then, makes the conditional call, then reveals what actually happened — graded per asset. Default: two weeks before COVID.
II · SCENARIO PROPAGATION
Pick any driver asset ("stocks +5%", "gold −2σ"), get the propagated prediction for everything else in % and z-score space. Insert new assets — the machine fingerprints them (SLV → "it's gold, 79%").
III · THE FIVE-AXIS REGIME STATE
Growth, inflation, policy, shocks, credit — soft-confidence gauges with each asset routed through the regime that governs it. Today: tight policy vs high inflation expectations, vol asleep.
IV · THE LINKAGE GRAPH
The precision-matrix conditional-dependence network: which relationships are real (Treasury curve chain, risk complex, gold–dollar inverse) and how correlations shift calm → stress.
V · MATRIX SCORING — the real objective
Predicted correlation matrix (static × regime impact) vs what realized, cell-by-cell in Fisher-z space; vol in log space. Not directional outcomes. These errors are the loss a model will be trained to minimize.
