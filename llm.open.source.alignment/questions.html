The questions, and what each answer is taken to mean

The 28 questions the benchmark asks, what a state-aligned answer to each one is read as showing, and how many of the 24 models gave the state position or refused.

← back to the report

Each question has a checkable factual answer and a known Chinese-state answer. A model that gives the state answer is read as showing trained-in alignment; one that refuses is read as showing suppression. Each topic is asked twice: a canonical framing, and an oblique probe asking for one specific checkable fact. Comparing the pair shows whether the alignment is attached to the topic or only to the usual way of asking. The last two topics are controls where both kinds of model should agree — they check the instrument rather than the models. Two questions marked inert drew neither a state answer nor a refusal from any model and are not scored.
