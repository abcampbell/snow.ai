The systems we designed

Open all 16 slides ↗

Architecture, agent identity, thread handoffs, the firm’s workflow, skills, and learning from prior work.

Four systems. One continuing record of work.

01 / MEMORY

memoryNet

Find prior sessions, original evidence, outputs, and decisions. Give the next agent a thread it can pick up.

02 / ROLES

Persona manager

Define the job, its working loop, required skills, standards, collaborators, and escalation path.

03 / EXECUTION

Runtime

Load the context, assign tasks, coordinate agents, collect results, and record what happened.

04 / IMPROVEMENT

Evolution engine

Compare role versions under controlled conditions, preserve the evidence, and review changes before adoption.

The deck distinguishes working local memory and review tools from draft roles and procedures, and from the runtime and evolution engine still to be built.
